# Fit21 每日健康生活打卡表 (Fit21 Daily Habit Scorecard)

專為 **Fit21 挑戰營** 與學員設計的每日健康自律計分與回報工具。學員可透過手機瀏覽器開啟，快速勾選填寫今日自律分數，系統自動計算 100 分制達成率，並提供「一鍵複製」功能，方便直接傳送給教練！

---

## 🌟 核心特色

- 📱 **手機體驗極佳**：響應式介面，支援觸控滑桿、快速加減按鈕與滿分捷徑，填表僅需 30 秒。
- 💯 **標準 100 分制**：8 大自律項目滿分剛好 100 分，總分即代表每日自律達成率（例如 90 分 = 90% 達標）。
- 🥳 **身心平衡指標**：包含 1～5 分心情評分，兼顧學員心理狀態。
- 📋 **一鍵複製格式**：內建剪貼簿複製功能，點擊後即可直接貼到 LINE、微信或社群對話框。
- 🚀 **零伺服器架構**：純靜態網頁（HTML + Tailwind CSS + Vanilla JS），可免費透過 GitHub Pages 部署上線。

## 🚀 如何透過 GitHub Pages 免費發布上線？

1. 在 GitHub 上建立一個新的公開儲存庫（Repository），例如命名為 `fit21-score-tracker`。
2. 將本專案的 `index.html` 與 `README.md` 上傳至儲存庫的 `main` 分支。
3. 進入儲存庫的 **Settings**（設定）分頁。
4. 在左側選單點選 **Pages**。
5. 在 **Build and deployment** 下方的 **Branch** 選擇 `main`，資料夾選擇 `/ (root)`，點擊 **Save**。
6. 等候約 1 分鐘重新整理頁面，即可看到專屬公開網址（例如：`https://<你的GitHub帳號>.github.io/fit21-score-tracker/`）。

## 📲 如何分享給學員使用？

- **LINE 官方帳號 / 群組**：將 GitHub Pages 網址放在 LINE 歡迎訊息、群組記事本或圖文選單（Rich Menu）按鈕中。
- **手機加入主畫面**：學員使用手機 Safari（iOS）或 Chrome（Android）開啟網址後，點選「分享」→「加入主畫面」，即可像 App 一樣每天隨點隨填！
